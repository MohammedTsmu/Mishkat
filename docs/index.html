هل التطبيق مجاني؟

نعم، مجاني بالكامل ومفتوح المصدر لويندوز 10 و11.

هل يعمل بدون إنترنت؟

القراءة والبحث والنسخ تعمل دائماً بدون إنترنت، ويمكن تنزيل التلاوات والترجمات مسبقاً للاستماع والترجمة دون اتصال.

هل الواجهة بالعربية؟

نعم، الواجهة كاملة بالعربية مع اتجاه يمين-لليسار، واللغة الافتراضية للموقع عربية.

كيف يحسب أوقات الصلاة؟

تُحسب محلياً على جهازك من موقعك التقريبي (يُحدد مرة واحدة ثم يعمل دون إنترنت).

Does it work on Windows 10 and 11?

Yes — Windows 10 and 11, both 64-bit. It needs the .NET Desktop Runtime (the installer offers guidance if missing).

Is the memorization mode suitable for beginners?

Absolutely — you pick a small range of verses, listen to each one several times, then recite it from memory with the text hidden. Reviewed verses come back automatically on a spaced schedule.
